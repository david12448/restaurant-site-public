# 맛집 사이트 화면/데이터 설계 v1

- 맛집 검색과 지역/음식/방송/공식 주차 필터, 검색 결과에 독립적인 식당 상세 보기.
- 연예인 유명세나 방송 횟수만으로 추천 순위를 만들지 않는다. 미검증 리뷰 수/평점으로 순위·인기도 암시하지 않는다.
- 리뷰: 네이버 방문자·네이버 블로그·카카오 장소 등 분리; 수치 있으면 수집일 명시, 허가 없으면 확인되지 않음으로 표시.
- 주차: 공식 매장 주차 안내와 제보 받은 방문자 주차 경험 각각의 근거와 날짜. 주차장 보장/요금 현재성 과장 금지.
- 폐업·이전 **확인된** 경우 상단 눈에 띄는 안내 + 가게 이력 타임라인. 검색 불일치는 비공개 검토 큐로만.
- 방송/연예인: 출처·프로그램·방송일/회차, 직접 방문 vs 추천 구분, 협찬 표시를 유지. 출연 단서만으로 매장 정보 자동 병합하지 않음.
- 원본 링크/방송 다시보기는 server gateway가 구현·검증된 이후 공개 token을 연결하고, 그 전에는 비활성/근거 유형만 표시.
- 여행 프로젝트: 동일 공개 장소키; 재검증하지 않은 거리/식당을 '근처'로 주장하지 않음.
- 공개는 approved export; 검증 전에는 0건 알림. 다른 업체를 샘플 실제 맛집으로 꾸미지 않음.
