# Shared governance snapshot

Canonical source: david12448/project-common-rules/COMMON_RULES.md (central PR #1).

- Protect nonpublic collectors, parsers, raw snapshots, source registries, internal mappings and credentials. Publish only necessary normalized results; use server-side controls, pagination and reasonable rate limits. URL hiding is not security; respect lawful attribution.
- Record verified problems, root causes, attempted fixes, tests and prevention in docs/TROUBLESHOOTING.md. Do not fabricate historical incidents.
- Preserve existing files and behavior. Review PRs before merging and do not create automatic progress alerts.

Automatic central sync is not configured; this is a snapshot.
